คู่มือการใช้งาน (User Manual)

โปรแกรมจับภาพหน้าจอ Windows อัจฉริยะ ใช้งานง่าย เบาหวิว ไม่กินแรม

✨ จุดเด่นของโปรแกรม

  • ไฟล์เดียวจบ (Portable .exe): ไม่ต้องติดตั้ง ดับเบิลคลิกเปิดใช้งานได้ทันที
  • ไม่ดูดแรม ไม่กิน CPU (0% Idle): รันนิ่งๆ ใน System Tray ใช้แรมเพียง ~15 MB
  • ปุ่มลัด F1 อัจฉริยะ: ใช้ Low-Level Keyboard Hook ป้องกันไม่ให้ชนกับระบบ Bing Help ของ Windows
  • แถบเครื่องมือคู่ บน-ล่าง: แยกแถบวาดเขียน (บน) และแถบคำสั่งใช้งาน (ล่าง) สะอาดตา ไม่บังพื้นที่ทำงาน
  • รองรับหลายจอ & High-DPI: คมชัดระดับพิกเซลบนจอ Scaling 125%, 150%, 200%

🚀 ขั้นตอนการใช้งานง่ายๆ

เปิดโปรแกรม: ดับเบิลคลิกไฟล์ 1ThaiAiCapture.exe โปรแกรมจะไปรันรอใน System Tray (มุมขวาล่าง)
กดปุ่มลัด: กดปุ่ม F1 บนคีย์บอร์ดเมื่อใดก็ได้เพื่อเข้าสู่โหมดจับภาพ
ลากพื้นที่: คลิกเมาส์ซ้ายค้างแล้วลากเพื่อตีกรอบพื้นที่ที่ต้องการแคป

✨ Key Features

  • Single Portable Executable: No installation required. Runs directly anywhere.
  • Zero RAM / CPU Footprint: Runs quietly in the System Tray using only ~15 MB RAM.
  • Smart Global Hotkey (F1): Uses Low-Level Keyboard Hook to suppress Windows Bing Help interference.
  • Dual Top & Bottom Toolbars: Drawing tools on Top and action buttons on Bottom for a clean workspace.
  • Multi-Monitor & High-DPI Ready: Crisp pixel-perfect capture on displays with 125%, 150%, 200% scaling.

🚀 Quick Start Guide

Start App: Double-click 1ThaiAiCapture.exe. It sits quietly in your System Tray (bottom-right corner).
Press Hotkey: Press F1 anytime anywhere to enter capture mode.
Drag Area: Click and drag to select any rectangle on your screen.
Resize & Move Selection: Drag any of the 8 handles/borders to resize, or drag inside the box to reposition before copying or saving.
Annotate (Top Toolbar):
✏️ Pen ➡️ Arrow 🔲 Box ↩️ Undo

(Drawing tools float gracefully above your selection)

Export / Copy (Bottom Toolbar):
📋 Copy 💾 Save 🌐 1ThaiAi ✕ Close

(Click Copy to paste into LINE/Slack/Docs, or Save as PNG/JPG/BMP)
